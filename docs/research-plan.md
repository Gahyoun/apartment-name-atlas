# 연구 설계

설정일: 2026-09-28. 사용자가 선택한 1차 범위는 **전국 아파트**다. 일반 건물·오피스텔·상가는 별도 유형으로 확장한다.

## 관찰 단위와 모집단

기본 단위는 단지다. 동·세대·거래 행을 그대로 세면 큰 단지나 거래가 많은 단지가 과대표집된다. 원자료 식별자와 주소를 보존하고 단지 수준으로 묶는다. 이름이 같다는 이유만으로 서로 다른 단지를 합치지 않는다. 서로 다른 기관의 ID도 직접 동일시하지 않는다.

전국을 목표로 수집하더라도 실제 분석 모집단은 해당 출처에 수록된 단지다. 관리정보에 포함되지 않는 소규모·오래된 단지, 철거된 단지, 누락된 명칭 변경 이력이 있을 수 있다. 시도·준공 연대별 건수, 연도 결측률, 이름 결측률, 매칭 성공률을 먼저 제시한다.

초기 비교는 사용승인연도를 기준으로 10년 단위로 묶고, 최근 구간은 필요하면 5년 단위를 추가한다. 진행 중인 연대는 기간이 짧다는 사실을 표시한다. 서로 다른 관측일의 자료를 결합할 때는 기준일과 수집 범위를 명시한다.

## 이름을 어떻게 나눌까

NFKC 정규화와 공백 정리 후, 긴 사전 항목을 먼저 매칭한다. 원문은 별도로 보존한다. `롯데캐슬` 내부의 `롯데`와 `캐슬`을 다시 세지 않는다. 사전으로 설명되지 않는 부분도 삭제하지 않고 미분류로 남긴다. 이는 연구 목적의 의미 단위이며 언어모델의 서브워드 토큰과는 다르다.

| 분류 | 검토할 예시 | 원칙 |
|---|---|---|
| 브랜드 | 롯데캐슬·카이저·래미안·힐스테이트 | 브랜드 전체 표현을 우선 보존; 한 이름에 여러 브랜드 허용 |
| 건설사 | 회사명 표현 | 이름에 실제 나타난 부분과 시공사 메타데이터를 구분 |
| 지명 | 화명 등 | 주소·행정동 사전으로 검증; 이름만 보고 확정하지 않음 |
| 자연 | 그린·숲속·리버·파크 | 의미상 중의성이 있으면 검토 표시 |
| 고급·해외 이미지 | 팰리스 등 비브랜드 수식어 후보 | 브랜드 여부를 먼저 확인; 고급화 의도에 대한 인과 주장 금지 |
| 건물 유형 | 아파트·타워 | 시대 비교의 핵심 토큰과 분리 |
| 숫자·차수 | 1차·2단지 등 | 본명·동번호·차수 혼동을 검수 |
| 미분류 | 사전에 없는 잔여 문자열 | 원문과 위치를 보존하고 사전 개선에 사용 |

`화명 | 카이저 | 롯데캐슬`은 분절을 설명하기 위한 예시다. 화명의 지명 역할은 주소로 검증한다. 사용자 지정 분류(2026-09-28)에 따라 카이저와 롯데캐슬은 각각 브랜드다. 브랜드가 빠진 나머지 문자열을 전부 수식어라고 부르지 않는다.

### 기업과 브랜드의 관계

표면 토큰과 조직·브랜드 관계는 별도 층위다. `롯데캐슬`의 표면 범주는 `brand`, 모기업·그룹 관계인 `corporate_group`은 `롯데`로 기록한다. 이때 롯데를 추가 표면 토큰으로 만들지 않는다. 여기서 모기업·그룹은 사용자 연구 분류이며 법적 직접 지배관계나 실제 시공사를 자동으로 확정하는 필드가 아니다.

`카이저` 역시 `brand`로 분류한다. 롯데캐슬과 함께 나타난다는 사실만으로 두 브랜드의 법적 관계나 상하위 브랜드 관계를 만들어내지 않는다. 관계가 확인되지 않은 브랜드의 `corporate_group`은 비워 둔다. 브랜드와 자연·고급 이미지가 동시에 연상되는 경우에도 기본 역할과 의미 태그를 혼동하지 않는다. 의미 태그의 다중 부여는 후속 확장 사항이다.

짧은 항목은 긴 고유명사의 일부일 수 있다. 예컨대 특정 두 글자 브랜드가 다른 단어 속에서 우연히 나타나는 경우를 경계한다. 가장 긴 매칭도 정답을 보장하지 않으므로 사전 버전, 잠정 분류, 검토 필요 여부를 출력한다. 형태소 분석기와 문자 n-gram은 나중에 비교 실험으로 추가할 수 있다.

## 지표

토큰 포함 비율은 `해당 토큰을 한 번 이상 포함한 단지 수 / 같은 지역·연대의 유효 단지 수`로 계산한다. 한 이름 안에 같은 표현이 여러 번 나와도 해당 단지는 한 번만 센다. 원시 빈도와 표본 수를 함께 제공한다. 여러 토큰이 공존하므로 모든 토큰 비율의 합은 100%를 넘을 수 있다.

첫 분석기가 제공하는 범위는 지역·준공 연대별 토큰 비율과 평균 이름 글자 수다. 이후 다음을 추가한다.

- 이름 길이와 토큰 수의 분포: 평균과 함께 중앙값·사분위수 비교
- 브랜드 포함 비율, 브랜드 다양성, 이름당 브랜드 개수, 복수 브랜드 결합, 카테고리 조합과 순서
- 브랜드와 수식어의 동반 출현: 단지수와 조건부 비율을 함께 표시
- 시도별 추세와 전국 집계; 필요하면 동일한 지역 구성으로 표준화한 비교
- 명칭 변경 전후의 토큰 추가·삭제, 이름 길이 변화

명칭 이력의 날짜가 데이터베이스 등록일인지 실제 변경일인지 확인한다. 이전 이름이 언제부터 쓰였는지 불명확하면 기간의 시작을 추정해 채우지 않는다. 관측된 최초 등장과 역사상 최초 등장을 구분한다.

## 품질 확인

첫 실제 표본은 가능하면 지역·준공 연대·브랜드 유무를 나눠 200개 정도를 수동 확인한다. 원문, 사전 분절, 사람이 판단한 경계, 범주, 오류 유형을 남긴다. 부족한 집단은 표본 수를 공개한다. 이는 출발 목표이며 통계적 대표성을 보장하는 숫자는 아니다.

이름 보존, 겹친 토큰의 이중 집계 방지, 결측 연도의 연대 집계 제외, 단지 ID 중복 차단을 기계적으로 확인한다. 사전 변경 전후 분절 결과를 비교하고, 미분류·잠정 매칭이 전체 결과에 얼마나 영향을 주는지 보고한다.

주요 대안 설명은 지역 구성, 신축 공급량, 기존 단지의 개명, 철거·생존 편향, 자료원별 수록 범위다. 이름의 변화에서 주민 선호나 가격 효과를 곧바로 추론하지 않는다.

## 만들 그래프

1. **토큰 타임라인:** 준공 연대별 토큰 포함 비율과 표본 수; 현재명 기준임을 제목에 표시
2. **단어 열지도:** 자주 보이는 표현 × 준공 연대; 브랜드와 일반 수식어 별도 필터
3. **이름 길이 분포:** 같은 지역 안에서 연대별 비교
4. **조합 탐색:** 브랜드를 선택하면 함께 붙는 지명·수식어와 원문 확인
5. **개명 전후:** 검증된 이력만 연결해 추가·삭제 토큰 표시

실데이터가 없는 상태에서는 시대별 추세 그래프를 채우지 않는다.
