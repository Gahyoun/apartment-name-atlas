## 이름과 시간 처리

현재명 선택은 `단지명_공시가격 → 단지명_건축물대장 → 단지명_도로명주소`의 첫 비공란 값이다. 이번 아파트 표본은 공시가격 명칭이 모두 있어 **46,385개 전부 공시가격 명칭**을 사용했다. 다른 두 명칭도 `name_variants`에 보존한다.

- 공시가격 명칭 결측: 0개
- 건축물대장 명칭 결측: 7,046개
- 도로명주소 명칭 결측: 6,217개
- 비공란 명칭이 자료원 사이에서 하나라도 다른 단지: **31,282개**
- ID 중복·충돌: 0개
- 사용승인일 형식 오류·누락·미래연도: 0개
- 사용승인연도 범위: **1961–2025년**

명칭 불일치는 단순 표기 차이일 수도 있고 브랜드·개명 반영 시점 차이일 수도 있다. 이 자료의 명칭을 곧바로 현재 분양 홍보명이나 현장 간판명과 동일시하지 않는다. 기본 선택을 바꾸면 토큰 비율도 달라질 수 있으므로 후속 분석에서 세 명칭 기준의 민감도 비교가 필요하다.

`approval_year`는 사용승인연도이고, `observed_at`은 이 원본을 수집한 날짜다. 어느 것도 최초 명명연도가 아니다. 이번 작업에서 명칭 변경 이력은 수집하지 않았다. 1990년 승인 단지에 특정 표현이 나타나도 그 표현이 1990년부터 쓰였다는 증거는 아니다.

## 서울 좌표 연결 규칙

다음 조건이 모두 성립한 경우에만 REB 단지에 서울 좌표를 붙였다.

1. 시도 접두사·연속 공백만 정리한 도로명주소가 정확히 일치한다.
2. 그 주소를 가진 단지가 **양쪽 자료에 각각 하나**뿐이다.
3. 법정동명이 정확히 같다.
4. 사용승인일의 연·월·일이 정확히 같다.
5. 좌표가 숫자이며 경도 126.7–127.3, 위도 37.4–37.8 범위 안이다.

양쪽 주소가 유일한 후보 2,426쌍에서 법정동 불일치 9쌍, 승인일 불일치 30쌍, 좌표 결측·범위 이상 26쌍을 제외해 2,361쌍을 연결했다. 단지명 유사도만으로 연결하지 않았고, 아파트 이름을 좌표 자료의 이름으로 바꾸지도 않았다.

좌표별로 `coordinate_source_url`, `coordinate_source_id`, `coordinate_match_method`, `coordinate_basis`, `coordinate_observed_at`, `coordinate_precision`을 저장했다. 좌표값은 서울 포털의 경위도 형태 수치이며 현장에서 측량 정확도와 대표점의 의미를 독립 검증하지 않았다. GIS 거리 비교는 이 제한과 서울 표본의 선택 편향을 함께 표시해야 한다.

전국의 무료·키 없는 공식 단지 좌표 파일은 이번 수집에서 확보하지 못했다. REB 원본은 PNU를 제공하므로 후속 공적 필지/건물 공간자료 또는 정식 지오코딩 자료와 연결할 수 있다. 전국 좌표를 확보한 것처럼 지도에 채우지 않는다.

## 재현

프로젝트 디렉터리에서 실행한다. Python 표준 라이브러리와 TLS 인증서 검증을 켠 시스템 `curl`을 사용한다.

```bash
# 저장된 실제 원본에서 정제·서울 좌표 연결 재현
python3 scripts/collect_public_data.py --observed-at 2026-09-28

# 확인한 REB 2026-08-31 원본과 서울의 현재 공개 CSV 재다운로드
python3 scripts/collect_public_data.py --download --download-seoul
```

서울 공개 CSV는 실시간 갱신될 수 있으므로 재다운로드 결과가 이 수집본과 같다는 보장은 없다. 원본과 해시를 함께 보존하고 재수집 시 실제 관측일과 파일명을 갱신한다. 이 보고서의 수치와 해시는 2026-09-28에 확보한 파일 기준이다.
