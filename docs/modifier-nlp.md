# 브랜드·지명 제외 NLP 분석

목표는 전국 아파트의 현재 이름에서 기업·브랜드·지명을 제외한 뒤 반복되는 명칭 어휘를 찾는 것이다. 이름 문자열을 무조건 형태소로 쪼개면 브랜드 일부가 일반 단어로 오인되므로 고유명 보호와 형태소 분석을 함께 사용한다.

## 단위와 분모

관측 단위는 한국부동산원 자료에서 아파트로 분류된 고유 단지 ID다. 같은 단지명 안에서 같은 토큰이 반복돼도 빈도는 1이다. 전국 포함 비율은 전체 단지 수를 분모로 사용하고, 사용승인 연대별 비율은 해당 연대의 전체 단지 수를 분모로 사용한다. 토큰을 제거한 뒤 남은 이름이 없는 단지도 분모에서 빠지지 않는다.

분석 대표명은 공시가격 DB의 현재 이름이다. 같은 이름의 서로 다른 단지는 별도 관측으로 유지한다. 이름의 공백과 전각 문자를 정규화하되 원문과 정규화명 내 문자 위치를 모두 보존한다.

## 분절과 분류

1. 브랜드·기업·검증된 지명은 긴 표현부터 겹치지 않게 보호한다. 롯데캐슬과 카이저는 각각 브랜드이며, 롯데캐슬에서 롯데나 캐슬을 다시 세지 않는다.
2. 주소에 근거한 지역 후보를 제외한다. 전국 동 이름 전체를 모든 단지명에서 부분 문자열로 지우는 방식은 사용하지 않는다. 다른 지역의 동명과 겹치는 일반어까지 지울 수 있기 때문이다.
3. 숫자·차수·주거 형식을 분리하고 연속된 잔여 구간에 Kiwi를 적용한다. 아파트명에 자주 쓰는 차용어와 한국어 표현은 네이밍 사전으로 보완한다.
4. 결과를 원문과 대조해 검수한 수식어 후보, 주거 형식, 미검토 고유명·형태소 후보로 나눈다. 불확실한 잔여 표현을 모두 수식어로 확정하지 않는다.

`아이파크`의 파크, `꿈에그린`의 그린, `포레나`의 포레는 브랜드 내부이므로 제외한다. 복합 표현의 분절 기준은 코드와 사전에 기록한다. 새 NLP 결과는 기존 지도 페이지의 탐색용 토큰과 별도로 계산하므로 수치가 다를 수 있다.

## 두 가지 집계 기준

기본 순위는 검수 어휘가 원문 위치를 보존한 명사로 분절되면 포함한다. 같은 잔여 구간에 미검토 고유명·외국어 형태소(NNP·SL·SH)가 있으면 `context_requires_review`를 붙인다. `strict_count`는 그런 이웃이 없는 구간에서 추출된 단지만 센다. 이는 특정 분절 조건에 대한 민감도 비교이며 정확도의 신뢰구간이 아니다. Kiwi가 일반명사로 잘못 판단한 고유명, 사전에 빠진 브랜드까지 검출하는 기준은 아니다.

웹페이지의 `context_only_count`는 기본 집계에만 포함되고 엄격 집계에는 없는 단지 수다. 감사 원본 모듈의 `context_review_count`는 문맥 검토 occurrence가 있는 단지 수이므로 두 종류 occurrence가 모두 있는 단지는 엄격 집계와 겹칠 수 있다. 공개 집계에서는 차집합을 사용해 합계가 기본 집계와 일치한다.

철자가 다른 로얄/로열은 로열, 씨티/시티는 시티로 묶는다. 리버뷰·파크뷰·오션뷰·레이크뷰·스카이뷰는 앞 표현과 뷰를 나누고, 포레스트는 하나의 어휘로 보존한다. 어휘 사전 검수는 일반 명칭 후보를 고르는 절차이지 개별 단지의 명명 의도를 확정하는 절차가 아니다.

## 무엇을 뜻하지 않는가

- **모든 브랜드·지명을 완벽하게 제거한 전수 어휘 순위가 아니다.** 동음이의어와 미확인 브랜드가 있어 검토 대상으로 남긴다.
- 사용승인연도가 명명연도인 것은 아니다. 오래된 단지의 현재 이름에는 개명·재브랜딩 결과가 들어갈 수 있다.
- 신축과 구축의 어휘 비율 차이는 인과효과나 주민 선호 변화의 직접 추정이 아니다.
- 사진 속 ‘작명법’의 빈도를 집계했다고 해서 그 시설이 실제 주변에 있다는 뜻은 아니다. 입지 검증은 별도의 좌표·시설 자료가 필요하다.

## 재현과 감사

```bash
python3 -m venv .venv-nlp
.venv-nlp/bin/python -m pip install -r requirements-nlp.txt
.venv-nlp/bin/python scripts/analyze_modifiers.py
```

- `src/modifier_nlp.py`: 보호·형태소 분석·분류
- `dictionaries/nlp-entities.json`: 추가 기업·브랜드·지명 보호 사전과 근거
- `dictionaries/nlp-modifiers.v1.json`: 검수해 추가한 명칭 어휘
- `work/nlp/full-analysis.json`: 추출 위치, 제외 사유, 미검토 후보 감사 자료
- `results/modifier-analysis.md`, `results/modifier-analysis.json`: 결과와 해석
- `frontend/data/modifier-analysis.json`: 웹페이지용 집계 스냅샷

[Kiwi 공식 문서](https://github.com/bab2min/kiwipiepy), [한국부동산원 원자료](https://www.data.go.kr/data/15106861/fileData.do)를 사용했다. 모델 버전과 입력 파일 SHA-256은 결과 JSON에 기록한다.
