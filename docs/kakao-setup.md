# 카카오맵 설정

JavaScript 키는 프로젝트 `.env.local`의 `KAKAO_MAP_JS_KEY`에 저장한다. 서버는 해당 항목만 `/api/map-config`로 화면에 제공한다. JavaScript SDK 키는 브라우저에서 사용되는 값이며 서버용 REST 키와 구분한다. `.env.local`은 Git 제외 대상이다.

기본 개발 주소는 `http://127.0.0.1:53052`다. 카카오 개발자 콘솔에서 해당 JavaScript 키의 **JavaScript SDK 도메인**에 이 주소를 등록한다. `localhost`를 쓰거나 포트를 바꾸면 실제로 사용하는 출처와 등록한 값이 맞아야 한다. 자세한 메뉴와 절차는 [카카오 지도 공식 가이드](https://apis.map.kakao.com/web/guide/)를 참고한다.

```bash
bash run.sh
```

화면은 카카오 SDK가 정상 연결되면 카카오맵을 사용한다. SDK 로드나 권한·도메인 설정 때문에 연결되지 않을 때는 사유를 표시하고 기존 OpenStreetMap 지도로 전환한다. 그래프와 거리 분석은 저장된 실데이터를 사용하므로 지도 제공자 설정과 무관하게 작동한다.

지도 배경은 카카오, 거리 측정에 사용한 지형 도형은 OSM이라는 출처 구분을 유지한다. 카카오 배경에서 보이는 시설까지의 거리를 실시간으로 계산하는 것이 아니다. 배경 지도 제공자 교체로 계산 결과를 바꾸지 않는다.

2026-09-28 공개 페이지는 `https://gahyoun.github.io/apartment-name-atlas/`에 게시했다. 실제 게시 출처를 지정한 SDK 응답 검사에서 HTTP 200과 정상 지도 로더를 확인했다. `http://127.0.0.1:53052` 개발 출처는 도메인 불일치 HTTP 401을 반환해 OpenStreetMap으로 전환되는 것을 브라우저에서 확인했다. 로컬에서도 카카오를 쓰려면 그 출처를 별도로 등록한다.

공개 페이지를 Chrome에서 실제로 열어 **기본 지도: 카카오맵** 표시, 확대·축소 제어, 단지 클러스터, GIS 도형 렌더링을 확인했다. 전국 46,385개 집계와 서울 좌표 2,361개도 정상적으로 로드됐다.
