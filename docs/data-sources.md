# 데이터 출처와 수집 순서

공식 안내 확인일: **2026-09-28**. 이후 공개 파일 다운로드로 한국부동산원 전국 아파트 46,385개와 서울 좌표 자료 2,893행을 실제 확보했고, 2,361개 단지에 좌표를 연결했다. 자세한 파일·행 수·검증은 [수집 기록](collection-report.md)을 참조한다. 아래 API 후보 중 인증 API 호출과 명칭 이력 수집은 아직 수행하지 않았다.

## 전국 아파트 기본 표본

[국토교통부 공동주택 기본 정보제공 서비스](https://www.data.go.kr/data/15058453/openapi.do)는 K-apt 가입 단지의 기본정보를 제공한다. 활용신청과 인증키가 필요한 API다. 전국을 다루는 출발점으로 검토하되 모집단을 ‘전국 모든 아파트’가 아니라 ‘출처에 포함된 단지’로 정의한다. 최신 상세 응답에서 단지 식별자·명칭·주소·사용승인일을 확인한 뒤 필드 매핑을 확정한다.

실제 수집 전 할 일: 단지 목록 조회 방식, 페이지 이동, 호출 제한, 단지 분류, 준공 연대별 커버리지 확인. 과거 문서의 필드명을 추측해 동작하는 수집기라고 표시하지 않는다.

## 전국 식별자와 이름 변경 이력

[한국부동산원 공동주택 단지 식별정보 조회 서비스](https://www.data.go.kr/data/15106817/openapi.do)는 기본정보·동정보·**단지명 이력정보** 제공을 안내한다. 명칭 이력을 이용한 분석의 우선 후보다. 활용신청 후 이력의 날짜 의미, 최초 수록 시점, 변경 전후 이름, 연결 가능한 단지 ID를 실제 응답과 기술문서로 확인한다. 서비스가 이력을 제공한다는 사실만으로 1990년대부터 모든 변경을 복원할 수 있다고 보지 않는다.

[기본정보 파일데이터](https://www.data.go.kr/data/15106861/fileData.do)는 CSV로 단지고유번호·주소·여러 DB에서 온 단지명·단지종류·사용승인일 등을 제공한다. 파일은 로그인 없이 다운로드할 수 있다고 안내한다. 아파트·연립·다세대가 함께 있으므로 아파트를 선택해야 한다. 공시가격·건축물대장·도로명주소의 단지명은 서로 다른 필드이므로 불일치와 출처를 보존하고, 현재명 선택 규칙을 먼저 정한다.

해당 페이지에는 전년도 사용승인된 공시대상 공동주택 기준이라는 설명과 과거 파일 목록이 있다. 실제 내려받은 2026-08-31 파일에는 1961–2025 사용승인 아파트가 들어 있었다. 이 파일은 여러 준공 연대를 포함하지만 철거된 단지와 과거 명칭을 복원하는 자료는 아니다. DB 간 기준시점·매칭 차이로 이름이 공란일 수 있다.

## 서울 자료: 필드 교차 확인용

[서울시 공동주택 아파트 정보](https://data.seoul.go.kr/dataList/OA-15818/A/1/datasetView.do)는 아파트 기본정보와 Sheet·파일·Open API 이용 안내를 제공한다. 전국 연구의 일부 지역에 대한 교차 확인용으로 쓴다. API 샘플과 정식 인증 방식이 구분되어 있으므로 실제 응답을 받아 명칭·사용승인일·지역 필드를 확정한다. 서울 자료만으로 전국 추세를 발표하지 않는다.

## 일반 건물로 확장할 때

[국토교통부 건축HUB 건축물대장정보 서비스](https://www.data.go.kr/data/15134735/openapi.do)는 건축물대장 관련 정보를 제공한다. 아파트 밖으로 확장할 때 검토하되, 단지와 건물 동의 단위를 구분한다. 건물명·사용승인일의 최신 필드와 식별자 체계는 첨부 가이드와 실제 응답으로 검증한 뒤 사용한다.

## 권장 진행 순서

1. 전국 기본정보의 접근 방식과 수록 범위를 확인하고 원본을 저장한다. 다운로드 가능한 파일과 인증 API 중 실제 확보 가능한 경로부터 사용한다.
2. 단지명·단지 ID·사용승인일·시도명이 있는 작은 실제 표본을 만든다. 서로 다른 명칭 출처를 섞을 때 선택 규칙을 기록한다.
3. 이름 분절과 기업·브랜드 관계를 수동 검수한다. 카이저는 사용자 분류 기준에 따라 브랜드로 다룬다.
4. 전국 수집을 확장하고 누락·중복·연대별 표본 수를 먼저 보고한다.
5. 이름 변경 이력을 연결한다. 연결이 안 된 단지도 버리지 말고 현재명 분석에 남기며, 두 분석의 분모를 구분한다.

## 수집 기록

각 원본 파일과 함께 자료명, 원문 URL, 내려받은 날짜, 자료 기준일, 원본 파일명, 행 수, 필드 목록, 추출 조건, 단지 유형, 자료 이용조건을 기록한다. 이름이 비거나 출처 간 충돌한 건수도 남긴다. 실제 API 키는 기록하지 않는다.
