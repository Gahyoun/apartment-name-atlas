# 너의 아파트 이름은.

**전국 아파트 이름 속 브랜드와 수식어는 어떻게 유행하고, 서로 결합해 왔을까?**

`그린숲속아파트`와 `화명카이저롯데캐슬`처럼 이름을 구성하는 조각을 모아, 지역과 시기에 따라 비교하는 탐색 프로젝트다. 두 이름은 사용자가 제시한 설명용 예시이며, 존재 여부·준공연도·역사적 명칭은 아직 검증하지 않았다.

## 먼저 보고 싶은 것

- ‘그린·숲·파크·리버’ 같은 자연 표현은 어떤 준공 연대와 지역에서 많이 보일까?
- 브랜드가 포함된 이름의 비중과 이름 길이는 어떻게 다를까?
- `지명 → 브랜드 → 수식어`, `지명 → 수식어 → 브랜드` 중 어떤 조합이 많이 보일까?
- 이름 변경 과정에서 무엇이 붙고, 무엇이 사라질까?
- 같은 브랜드라도 부산·서울·경기 등 지역에 따라 붙는 수식어가 다를까?

분류는 **기업 관계와 이름의 표면 토큰을 나눠서** 다룬다. 사용자의 기준에 따라 `롯데`는 모기업·그룹, `롯데캐슬`과 `카이저`는 각각 브랜드로 둔다. `롯데캐슬` 안의 `롯데`는 관계 정보로 연결하고 토큰 빈도에서 다시 세지 않는다. 한 단지명에 브랜드가 여러 개 붙는 경우도 분석 대상이다.

‘과거에는 자연 이름, 최근에는 고급 브랜드’라는 이야기는 **검증할 가설**이다. 아직 분석 결과가 아니다.

## 두 가지 시간축

| 분석 | 비교하는 것 | 해석 |
|---|---|---|
| 1차: 준공 연대별 현재 이름 | 수집 시점의 명칭 × 사용승인연도 | 어떤 시기에 지어진 단지가 지금 어떤 이름을 쓰는가 |
| 2차: 이름 변경 이력 | 같은 단지의 이전·이후 이름 × 변경 시점 | 어떤 표현이 실제로 추가·삭제되었는가 |

현재 이름을 1990년 준공 단지에서 발견했다고 해서 그 표현이 1990년부터 쓰였다고 결론 내리지 않는다. 사용승인일·명칭 관측일·명칭 변경일을 구분한다.

## 웹에서 탐색하기

공개 페이지 배포 주소는 [너의 아파트 이름은.](https://gahyoun.github.io/apartment-name-atlas/)다. 소스는 [Gahyoun/apartment-name-atlas](https://github.com/Gahyoun/apartment-name-atlas)에서 관리한다. 정적 배포 구성과 재생성 방법은 [GitHub Pages 안내](docs/github-pages.md)에 있다.

터미널에서 이 프로젝트 폴더로 이동한 뒤 `bash run.sh`를 실행하고 `http://127.0.0.1:53052`를 연다. 지도 SDK 도메인 등록을 유지하기 위해 포트를 고정했다. 다른 포트가 필요하면 `PORT=8080 bash run.sh`처럼 지정하고 카카오 SDK 도메인도 맞춘다.

화면은 사용자가 제공한 KRDS 참고 문서의 색상·글자 크기·여백·포커스 스타일을 적용한 독립 연구용 도구다. 정부기관의 공식 서비스나 접근성 인증을 받은 제품이라는 뜻은 아니다.

- **지역 필터:** 시도 → 시군구 → 법정동, 사용승인연도 범위
- **토큰 그래프:** 선택 기간의 누적 단지 수, 연도별 포함 비율
- **이름 분해:** 기업·그룹, 브랜드, 지명, 개별 명칭·미분류, 자연·기타 표현
- **지도:** 카카오맵 배경, 실제 확인한 단지 좌표와 OSM 지형·시설. 카카오 연결 실패 시 OpenStreetMap으로 전환
- **입지 비교:** 토큰 보유·비보유 단지의 직선거리. 로컬 Python API는 같은 시군구·준공 연대 내 순열검정도 제공하며 공개 정적 페이지는 조건별 거리 요약을 계산

## 실제 연결된 자료

전국 **46,385개 아파트 단지**, **17개 시도**, 사용승인연도 **1961–2025**를 수집했다. 전국 REB 파일에는 좌표가 없어서 서울시 공식 자료와 도로명주소·법정동·사용승인일이 모두 일치한 **2,361개**에만 좌표를 붙였다. GIS는 이 서울 표본에서 공원·수면·숲·학교·지하철 5종까지의 거리를 측정한다. 전국 GIS가 완료된 상태는 아니다.

분석의 기본 명칭은 공시가격 DB의 현재 이름이다. 기관별 명칭이 다른 단지 **31,282개**는 원문 변형도 함께 보존했다. 실제 최초 이름이나 홍보명과 같다고 보장하지 않는다.

## 바로 실행하기

Python 3.10 이상에서 외부 라이브러리나 API 키 없이 토큰 분절 예제를 실행할 수 있다. 터미널에서 이 프로젝트 폴더로 이동한 뒤 실행한다.

```bash
python3 src/analyze.py --input data/examples/names.jsonl --output-dir work/demo --allow-demo
python3 -m unittest discover -s tests -v
```

`work/demo/tokens.jsonl`에는 원문과 분절 결과, `review.jsonl`에는 검토 대상, `summary.json`에는 집계와 해석 주의사항이 저장된다. 데모 출력의 숫자는 실측 결과가 아니다.

전국 자료 수집과 웹앱용 변환을 다시 실행하려면 다음 명령을 사용한다. 공개 원자료 다운로드에는 인터넷 연결이 필요하다.

```bash
python3 scripts/collect_public_data.py --download --download-seoul
python3 scripts/build_report.py
```

현재 웹 입력은 `data/processed/complexes.jsonl`이다. 위의 단순 CLI 데모와 웹앱 입력 규격은 다르다. 웹 서버와 보고서 생성은 Python 표준 라이브러리를 사용한다. 오프라인 GIS 거리 재계산에만 `requirements-gis.txt`의 Shapely·PyProj가 필요하다. 지도 표시는 인터넷 연결이 필요하며 카카오는 JavaScript 키를 사용한다. OpenStreetMap 대체 지도는 키 없이 동작한다. [카카오 설정](docs/kakao-setup.md)을 참고한다.

공개 저장소의 `site/`에는 실제 수집 자료에서 내보낸 분석용 스냅샷이 포함된다. 원본 CSV와 로컬 환경 파일은 포함하지 않는다. 소스를 새로 내려받아 Python API를 실행하려면 위 수집 명령으로 `data/processed/`를 먼저 생성한다. 공개 스냅샷을 그대로 보는 경우에는 `python3 -m http.server 8080 --directory site`만 실행하면 된다.
